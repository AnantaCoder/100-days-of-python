## 🧾 Important Numerical Formulas to Remember

* **TLB EAT** = (Hit ratio × TLB time + Memory time) + (Miss ratio × (TLB + 2×Memory time))
* **Page Table Size** = (Virtual address space / Page size) × Size of page table entry
* **CPU Utilization** = Total CPU burst time / Total time × 100
